Poindexter

Turn a PDF presentation into a PowerPoint file of slide images.

Download for macOS Latest release · macOS 14 or later · All releases · Source

Poindexter is for quickly repackaging a finished PDF talk (LaTeX beamer or anything else) so it can be shown from PowerPoint or Keynote. Each page is rendered as a high-resolution image and placed on its own slide, so it looks exactly like the PDF.

It is not a full-fidelity conversion

  • Slides are pictures. Text, equations and figures can't be edited in PowerPoint.
  • Links aren't clickable, and embedded video, audio and animations don't carry over.
  • Beamer overlays become separate slides, or one slide per frame if you choose.
  • Each page's text is copied into the speaker notes and image alt text, so it can be searched and read by screen readers.

If you need editable slides, rebuild the deck in PowerPoint from your source.

Private by design

Everything runs on your Mac. Your PDFs are never uploaded.
